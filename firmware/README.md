# Firmware files

Supply firmware built for your own keymap. Keep left and right files from the same build and name them `glove80_lh-zmk.uf2` and `glove80_rh-zmk.uf2`.

The `factory/` folder contains a fixed factory recovery pair and its original upstream keymap. The app bundles these files separately and selects them through Restore Factory Firmware. Their pinned provenance and checksums are recorded in that folder.
